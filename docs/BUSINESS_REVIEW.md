## 0. 결론

1. **지금 문제는 기능이 아니라 사용자가 0명이라는 점이다.** 최근 3주 가입 0, 로그인 사용자(일 합) 주 5~8(사실상 운영자),
   보유·관심 추가 0, 리포트 발행 0. 7일 nginx 기준 종목 페이지 8,296회 가운데 약 7,100회는 성장 감시 크롤러(1,017 URL/일)다.
   Google 색인은 46 / 미색인 1,040, 그리고 **Search Console·GA4·Bing이 아직 연결되지 않아 유입을 잴 수단이 없다.**
2. **메뉴 20여 개가 경쟁자만 20곳을 만든다.** 주식(토스 MAU 650만·미래에셋 373만·네이버), 부동산(호갱노노·아실·리치고),
   예적금·대출(뱅크샐러드·토스·네이버페이), 커뮤니티(토스·네이버 종토방). 영역마다 무료 대형 사업자가 있다.
   1인 27만 줄 코드로 모두를 유지하는 것은 사업화 단계에서 감당하기 어렵다.
3. **이길 수 있는 자리는 하나다 — 「한국어로 읽는, 검증된 KR+US 전 종목 점수」.** Simply Wall St(5축 눈송이, 유료)와
   초이스스탁US(22요인 스마트스코어, 미국만·유료)의 자리를 **국내+미국·무료·성적 공개**로 차지한다.
   데이터 집중 순서: **① 종목 점수·설명 ② 실적(일정·서프라이즈·요약) ③ 컨센서스·목표가 ④ 레딧 화제 종목**.
   부동산·예적금·뉴스·커뮤니티는 **유입 수단이 아니라 보조 기능**으로 낮춘다.
4. **그런데 그 핵심 데이터에 결함이 있다.** 국내 PER·ROE·성장률이 최신 **연간 사업보고서**만 써서(10월에 FY2025 기준)
   삼성전자가 「분기 영업익 107조」인데 PER 39.8배·가치 19점으로 나온다. 뉴스 태깅은 「나스닥」 지수 언급 49건을 NDAQ 종목으로 센다.
   랭킹 성적은 KOSPI 대비 −0.45%p인데 메뉴 이름은 「AI **추천** 랭킹」이다.
5. **사업화의 선결 조건은 기능이 아니라 운영·법률이다.** 운영 서버가 개인 Windows PC(Docker Desktop·KT 가정 회선)이고,
   마지막 커밋이 09-15(미커밋 1,298파일)이며 저장소가 공개다. 시세(Toss OpenAPI 개인 자격증명)·네이버 컨센서스·FnGuide 내부
   엔드포인트·Reddit 글 전문 번역은 상업 이용 허락이 확인되지 않았다. 「추천」을 유료로 팔면 유사투자자문업 신고 대상이 될 수 있다.

### 2.3 종목 화면 첫 화면 제안 (위 → 아래)

1. 가격 · 등락 · **「왜 움직였나」 한 줄**(근거 1개 링크)
2. **점수 카드**: 5축 레이더 + 종합 + 「섹터 n개 중 m위」 + 어제 대비 변화(인공물이면 회색) + 「이 점수의 성적」 링크
3. **다음 실적 D-n** · 지난 서프라이즈 4분기 막대
4. 애널리스트 목표가(출처·기준일) · 90일 범위
5. 탭(AI 분석·재무·실적·내부자·뉴스·커뮤니티)
6. 비로그인이면 **「관심 등록하면 점수가 바뀔 때 알려 드려요」** 단추 — 검색으로 들어온 사람을 가입으로 바꾸는 유일한 지점

지금은 6개 탭 + 접힌 요약 바 + 카드 열 개 이상이 같은 무게로 나열돼 첫 화면에 「이 서비스만의 것」이 안 보인다.

## 4. 방문자를 늘리고 고객으로 바꾸는 법

### 4.1 측정부터 (지금 0)
- Search Console 서비스 계정 JSON · GA4 속성 ID · Bing 키 연결(`docs/GROWTH.md` §설정) — **3주째 대기 중**. 네이버 서치어드바이저는 인증 메타는 있으니 사이트맵 제출·수집 현황을 콘솔에서 확인.
- 퍼널 이벤트 4개만 정의: 검색 착지 → 종목 화면 2개 이상 → 관심 등록 → 7일 안 재방문. 지금 성장 보고서의 「활성화」 정의와 맞춘다.
- 주의: 탭 제목이 모든 화면에서 「마지막으로 본 종목 시세」로 바뀐다(`quote-tab-title.tsx`, 09-15 요청). GA4의 page_title이 오염되므로 **보고는 page_path 기준**으로 잡는다.

### 4.2 검색 유입 (주 채널, 무료)
- **실적 시즌 페이지**: 「삼성전자 실적 발표일」「엔비디아 실적」류는 분기마다 급증한다. 실적 이벤트마다 색인 가능한 URL(예정일·컨센서스·서프라이즈 이력·발표 뒤 AI 요약)을 만든다. 성장 보고서도 「7일 안 실적 발표 색인 대상 45종목」을 1~2순위 기회로 매일 올리고 있다.
- **색인 범위**: 종목 1,000 → 색인률이 오르면 3,000 → 전 종목. 섹터·테마 허브(「반도체 점수 순위」)는 서버 렌더로.
- **매일 바뀌는 날짜 페이지**: 「오늘의 변화」를 날짜별 보관 URL로(지금은 CSR이라 서버 링크 0).
- **점수 성적표 공개 페이지**: 신뢰를 파는 서비스의 랜딩. 링크를 받을 만한 유일한 콘텐츠.
- 정책상품(청년미래적금 등)은 시즌 검색 폭이 커서 싼 유입원 — 상세 URL을 사이트맵에.

### 4.3 외부 유통 (승인 필요한 외부 게시)
- 국내 개인투자자 정보 소비는 **텔레그램 채널·네이버 블로그/카페·X**가 크다. 성장 보고서의 「외부 유통 후보」(점수 급변·공개 리포트)를 **하루 1회 자동 카드**(OG 이미지 = 5축 레이더)로 텔레그램 채널에 올리는 것이 가장 싸다.
- 장 마감 뒤 「오늘 점수가 가장 크게 바뀐 10종목(인공물 제외)」은 경쟁사가 못 만드는 콘텐츠다.

### 4.4 전환·재방문
- **소셜 로그인 없음**(아이디·비밀번호만). 카카오·네이버·구글 로그인은 국내 가입 전환의 기본값이다.
- **알림이 없다**(앱 안 배지만). 재방문 이유가 생기지 않는다. 1차는 **이메일 주간 요약 또는 텔레그램 봇**(관심 종목 점수 변화·실적 D-1) — 웹 푸시보다 싸고 국내 사용 습관에 맞다.
- 비로그인 체험: 관심 3종목까지는 로컬에 담게 하고, 알림을 켤 때 가입 — 첫 가치 전에 가입을 묻지 않는다.
- 홈 첫 화면: 모바일 첫 화면이 스켈레톤(브리핑·뉴스·랭킹이 클라이언트에서 22개 API로 채워짐). **가치 제안 한 줄 + 오늘 점수 변화 TOP**을 서버 렌더로.
