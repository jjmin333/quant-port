뉴스 개편 v2 — A3 LLM 입력 설계 · 비로그인 유도

v1에서 고르신 A1·A2·A3 / B1·B2 / C1·C2 / D1·D2 / E1~E4 중, 설계가 더 필요한 두 가지만 다룹니다.

⚠️ 이 코드베이스의 LLM 지출 규칙 — 설계가 여기서 갈립니다

stock_summary.go에 이렇게 못박혀 있습니다: “LLM 호출 진입점은 정확히 둘 — 예약 배치와 관리자 수동 실행. 일반 조회는 캐시가 아무리 낡았어도 절대 LLM을 부르지 않는다.” 하루 비용이 배치가 계획한 건수와 정확히 같아지는 것이 이 규칙의 목적입니다.

→ 그러므로 A3 브리핑도 사용자가 페이지를 열 때 생성하면 안 됩니다. 배치가 미리 만들어 두고, 화면은 저장된 것을 읽기만 합니다. 아래 선택지는 전부 이 전제 위에 있습니다. (지금의 규칙 기반 브리핑은 FE에서 즉석 계산이라 이 제약과 무관했습니다.)

1. A3 — LLM에 무엇을 넣을까 (입력 범위)

A3 카드의 숫자 4칸(기사 수·속보 수·지수·환율)은 LLM이 필요 없습니다. 이미 가진 값을 세면 됩니다. LLM이 맡을 것은 문장뿐입니다. 문제는 그 문장을 쓰라고 무엇을 보여줄 것인가입니다.

안입력토큰/회쓸 수 있는 문장 / 못 쓰는 문장
L1 상위 40건 제목 + 발행시각 + 매체 ~1,400 “반도체 관련 기사가 오늘 가장 많았다” ✅
“그래서 하이닉스가 4% 올랐다” ❌ (시세를 모름)
L2 추천 L1 + 지수 5개 등락 + 언급 상위 종목 10개(건수·등락률) + 속보 건수 + 시장 세션 상태 ~2,300 “HBM4 양산 발표 이후 SK하이닉스가 4.2% 올랐다” ✅
A1 스트립과 같은 집계를 보므로 카드와 문장이 어긋나지 않음 ✅
L3 L2 + 직전 브리핑 요약 1개 ~2,600 “어제의 외국인 순매도 흐름이 오늘 반전됐다” ✅ (연속성)
직전 문장이 틀렸으면 오류가 이어붙음 ⚠️
L4 L2 + 상위 15건 본문 요약문 ~7,800 가장 구체적. 토큰이 3배인데 제목만으로도 대부분 나옵니다 — 비용 대비 이득이 작습니다.

L2 입력 실물 — 실제로 이렇게 들어갑니다

// systemPrompt (고정)

O2추천

+ 시황·지켜볼 것

{
  "summary": "…2문장",
  "mood": "강세|중립|약세",
  "moodReason": "…한 줄",
  "highlights": ["…","…"],
  "watchPoints": ["…","…"]
}

위 카드 그대로 나옵니다. mood는 지수 등락과 어긋날 수 있어 배지 옆에 실제 지수 등락률을 항상 같이 둡니다.

O3

+ 종목 태그

{
  … O2 전체 …
  "highlights": [
    {"text":"…",
     "symbols":["000660"]}
  ]
}

highlight를 누르면 A1 스트립·목록 필터가 그 종목으로 걸립니다. 브리핑이 읽는 글에서 조작할 수 있는 것이 됩니다. 대신 LLM이 없는 심볼을 지어낼 수 있어 입력에 있던 심볼만 통과시키는 검증이 필요합니다.

3. A3 — 언제 생성할까 (비용이 여기서 정해집니다)

안시각 (국내 / 해외 각각)일 호출일 토큰체감
S1 개장 1시간 전 · 마감 30분 후 4~9,200 가장 쌉니다. 장중에 큰 뉴스가 터져도 브리핑은 아침 것 그대로 — 「15:20 생성」 표시가 무색해집니다.
S2 추천 개장 전 · 장중 2회 · 마감 후 8~18,400 장중에도 한 번은 갱신됩니다. 기존 AI 요약 배치(종목 수십 건)에 비하면 무시할 수준입니다.
S3 장중 2시간마다 + 개장 전 · 마감 후 14~32,000 거의 실시간. 기사 40건 중 대부분이 직전과 겹쳐 문장이 별로 안 바뀝니다.

어디서 돌까 — 기존 「AI 요약 배치」와 같은 자리, 즉 API 프로세스 안입니다(NewsStore·LLM 클라이언트를 그대로 써야 하므로). /admin/batch 카탈로그에 「AI 뉴스 브리핑 — 국내 / 해외」 두 줄을 추가해 수동 실행·이력도 됩니다.
LLM이 꺼져 있거나 실패하면 — 지금의 규칙 기반 브리핑으로 자동 대체하고 배지를 규칙으로 표시합니다. 화면이 비는 일은 없습니다.

4. 비로그인 — B1 「내 종목」 pill

지금 /watchlist·보유 조회는 로그인 필수입니다. 비로그인 사용자에게 이 pill을 어떻게 보일지 세 가지입니다.

G1추천

미리보기로 실제 동작 + 안내 띠

인기 종목(삼성전자·SK하이닉스·NAVER / 해외 NVDA·AAPL·TSLA)을 임시 「내 종목」으로 두고 필터가 진짜로 걸립니다. 기능을 써 본 뒤에 로그인을 권합니다.

전체속보 ⭐ 내 종목 18 · 예시 코스피코스닥SK하이닉스 14
⭐ 지금은 인기 종목 3개 기준입니다 — 삼성전자 · SK하이닉스 · NAVER. 로그인하면 내 보유·관심 종목으로 바뀝니다. 로그인 →
속보한국경제 SK하이닉스, HBM4 내년 1분기 양산 확정 +4.2%

왜 이게 낫나 — 잠긴 버튼은 “나중에”가 되지만, 써 본 기능은 “내 종목으로 바꾸고 싶다”가 됩니다. 예시임을 pill과 띠 두 군데에 표시해 오해는 막습니다.

골라 주실 것 — 6가지

항목선택지제 추천
① LLM 입력L1 / L2 / L3 / L4L2 — 뉴스와 시세를 잇는 문장이 나오면서, A1 스트립과 같은 집계를 봐서 카드·문장이 어긋나지 않습니다.
② 출력 스키마O1 / O2 / O3O2 — 「강세/약세」와 「지켜볼 것」이 A3 카드의 값어치입니다. O3(종목 태그)는 검증 코드가 더 붙으니 2차로 미루길 권합니다.
③ 실행 주기S1 / S2 / S3S2 — 하루 8콜. 기존 AI 요약 배치 대비 오차 수준입니다.
④ B1 비로그인G1 / G2 / G3G1 — 기능을 실제로 써 보게 한 뒤 권합니다.
⑤ D1 액션 비로그인G4G4 + ?next=에 기사 id까지 실어 보던 모달로 복귀.
⑥ E2 레일 비로그인G5 / G6G6 — 흐림 처리는 없는 데이터를 있는 것처럼 보이게 합니다.
