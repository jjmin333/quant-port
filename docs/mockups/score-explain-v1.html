AI 점수 설명 — 노출 범위 선택용 목업 v1

2026-09-17 · 숫자는 전부 운영 DB 실측값(005930·AAPL·035720, 2026-09-16 회차)

백엔드는 이미 배포돼 있다. GET /stocks/{symbol}/score/explain — 저장된 배치 산출물만 읽어 조립한다(실측 0.23초 · 15KB · 쿼리 1회 · LLM 0회 · 외부 호출 0회). 이 문서는 그 응답을 화면 어디까지 내보낼지를 고르기 위한 것이다.

왜 필요한가 — 설명을 만들고 나서야 보인 것. 점수의 하루 변동은 시장이 아니라 평가 축의 유무가 만들고 있었다:

종목전일 점수 변화그중 「축이 생기거나 사라져서」
AAPL+11+10.75 — 가치 축 소멸
005930 삼성전자+2−0.65 — 심리·수급 축 소멸
035720 카카오−2−1.62 — 심리·수급 축 소멸

AAPL의 어제 +11점은 회사에 아무 일도 없었고 가치 축 데이터가 빠져 분모가 줄었을 뿐이다. 지금 화면은 이걸 「점수가 올랐다」로만 보여 준다.

선택지 A

개요 점수 카드에 「변화 사유」 한 줄

종목을 열면 가장 먼저 보이는 카드. 모바일 개요 최상단이라 높이가 곧 비용이므로 한 줄로 제한하고, 누르면 AI 분석 탭의 전체 패널로 간다.

선택지 B

AI 분석 탭 — 전체 설명 패널 (신규)

한 종목을 펼쳤을 때 한 번 부르는 자리(15KB). 현재 이 탭에는 LLM 요약(전체 17,916종목 중 744종목 = 4%에만 있다)과 점수 추이선뿐이라, 점수가 있는 나머지 96%에게는 사실상 빈 탭이다.

선택지 C

보유 / 관심 목록 행에도 변화 사유

목록에서 바로 「무엇이 달라졌나」를 본다. 비용이 붙는 선택지라 아래에 실측 근거를 적었다.

선택지 D

관리자 점수 화면(/admin/score)에서 재계산 전후 대조

가중치를 바꾸거나 재계산을 돌린 뒤 무엇이 왜 움직였는지를 같은 패널로 본다. 사용자에게는 안 보이는 화면이라 위험이 가장 낮다.

결정해 주실 것

  • A (개요 한 줄) — 위험 낮음. 카드 높이 +28px. 모바일 개요 최상단이라 이 높이가 유일한 비용.
  • B (AI 분석 탭 패널) — 권장. 새 컴포넌트 하나(score-explain-panel.tsx), 기존 화면을 건드리지 않는다. 96%의 종목에서 빈 탭이던 자리가 채워진다.
  • C (목록 행) — 새 요약 API 하나가 더 필요하다(/scores/changes). 여기까지 하시려면 A·B 다음 회차로 미루는 편을 권한다.
  • D (관리자) — 위험 최저. 다만 「가중치 변경」 귀인은 BE 추가 작업이 있다.
