샘플 데이터는 어디서 오나

G-1. FE 고정 상수 추천

lib/sample-data/*.ts에 메뉴별로 한 벌씩 박아 둔다. 서버 요청 0회, 오프라인에서도 뜨고, 매번 같은 화면이라 설명 문장이 데이터와 어긋나지 않는다. 가격은 실제 종목명을 쓰되 값은 고정이므로 "예시"임이 분명하다.

G-2. 실시간 시세를 섞는다

종목은 고정하되 현재가만 실시간으로 채운다. 더 진짜 같지만 요청이 늘고, 장 마감·휴장일에 값이 비면 예시 화면이 깨진다. 무엇보다 "적중률 62%" 같은 숫자는 어차피 지어낸 값이라 절반만 진짜가 된다.

샘플 한 벌의 분량은 메뉴마다 3~6행 + 요약 숫자면 충분합니다 — 화면의 모든 상태(적중·빗나감·검증 중, 수익·손실)가 한 번씩 나오도록 고르는 것이 개수보다 중요합니다.
