## 5. 사업화 전에 할 일 (순서)

1. 🔴 가운데 **사용자에게 직접 보이는 것**부터: Reddit 본문 번역 → 네이버 컨센서스 → 로고(저장소 공개 포함) → Toss 실시간 재표시.
2. 시세는 「비로그인 = 종가/지연, 실시간 = 계약 뒤」로 가르는 설계를 미리 둔다(코드 쪽은 `source=db` 배지 BACKLOG와 같은 축).
3. 화면 출처 표기를 원천별로 점검(`ProvenanceStamp`).
4. 이 표를 법률 검토에 넘기고 회신을 이 문서에 적는다.
