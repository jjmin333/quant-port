### QP-03 · 원본 IP 직접 접속 차단 — P0 · 추천 3 · 🙋 nginx 변경 승인
- **문제**: nginx `server_name _`가 아무 Host에나 사이트 전체를 준다. Cloudflare WAF를 우회하는 길이 열려 있다(10-20 점검, IP 주소로 들어온 사용자의 오류 보고도 실제로 있었다). 7일 로그에 SQL 인젝션 탐침(`earnings/stats?from=…sleep(15)`)과 `/onvif`·`/mcp`·`/config.json` 스캔이 있다. 지금은 모두 400·404로 막히지만 원본이 드러나 있다.
- **할 일**: 기본 서버는 `return 444`로 끊는다. 공유기 포워딩은 Cloudflare IP 대역으로만 허용하거나 Tunnel로 바꾼다.
- **완료 기준**: `curl -H "Host: <공인IP>" http://<공인IP>/`의 연결이 끊긴다. 공개 도메인은 200 그대로다.

- **문제**: `quote-tab-title.tsx`(09-15 사용자 요청)는 문서 제목을 「224,000원 +7.18% | 삼성전자」로 바꿔 둔다. 이 동작은 종목 화면 자신에서도 일어난다. Google은 JS를 실행한 뒤의 제목을 쓰는 경우가 많다. 그러면 검색 결과 제목이 「삼성전자 (005930) 주가·AI 점수 · Quant Port」 대신 그때그때의 시세 문자열이 된다. 브랜드도 검색어(「주가」·「AI 점수」)도 빠진다.
- **할 일**: 봇 UA(`Googlebot|bingbot|Yeti|Daum`)에서는 덮어쓰기를 끈다. 사람에게는 지금처럼 보인다.
- **완료 기준**: Googlebot UA로 렌더하면 SSR 제목이 그대로 남는다. GSC URL 검사로 최종 확인한다(QP-01 뒤).

### QP-06 · 오류 원인이 안 남는다 — P1 · 추천 6
- **문제**:
  1. 클라이언트 오류 보고가 7일 1,283건(하루 약 180건)이다. 그런데 내용은 api 컨테이너 로그에만 있어 **재배포마다 사라진다.** 오늘 재생성 뒤에는 홈 React #418(하이드레이션 불일치)만 2건 남았다.
  2. 스크리너 `POST /stocks/screen`의 30%(360/1,200)가 400이다. 프리셋 전부와 「닮은 종목」 9개 심볼로 재현해 봤지만 모두 200이라, 원인이 봇인지 화면 버그인지 모른다.
  3. nginx 로그에 시각·UA·referer가 없다. 사람과 봇, 검색 유입을 구분할 수 없다.
- **할 일**: 클라이언트 오류를 하루×종류×경로로 DB에 집계한다(원문은 상위 N개만). 400 응답은 이유 코드를 로그로 남긴다. nginx `log_format`에 `$time_iso8601 $http_user_agent $http_referer`를 넣는다(nginx 변경이라 승인 필요).
- **완료 기준**: 「어제 오류 상위 5개와 그 경로」, 「스크리너 400의 이유」를 SQL 한 줄로 볼 수 있다.

### QP-10 · 시장 히트맵 — P1 · 추천 10 · 참고: Finviz·Koyfin
- **왜**: 「공유가 가장 많이 되는 화면」이다(`BUSINESS_REVIEW` §2.2). 줍줍·토스에는 **점수 변화 색 히트맵**이 없다. 우리 데이터(전 종목 점수와 일간 변화)로만 만들 수 있는 화면이다.
- **할 일**: `/market/heatmap`에 국내·미국 시가총액 가중 사각형을 그린다. 색은 등락과 점수 변화 중 고른다. 업종별로 묶는다. OG 이미지도 붙인다. 데이터는 저장된 점수와 종가만 쓴다(LLM 없음).
- **완료 기준**: 모바일에서 손가락으로 업종 확대가 된다. 공유 카드가 나온다.

### QP-11 · 무거운 화면 HTML — P2 · 추천 11
- **근거**: 뉴스 506KB, 분석 449KB, 시장 413KB. 종목 화면은 101KB다. 대부분 서버 컴포넌트가 실어 보내는 데이터(RSC 페이로드)로 보인다. 모바일 데이터와 첫 화면이 느려진다.
- **할 일**: 첫 화면에 필요한 목록만 서버에서 싣고, 나머지는 스크롤 시 받는다. 큰 JSON(전체 목록·차트 원자료)은 클라이언트 요청으로 돌린다.
- **완료 기준**: 세 화면 모두 200KB 이하. 모바일에서 화면 이동 전후를 육안으로 확인(메모리 `css_ui_regression_caution`).

### QP-13 · 목표가 신선도 — P2 · 추천 13

## 5. 차별점 — 지킬 것

| 우리 | 경쟁 | 판단 |
|---|---|---|
| 국내와 미국 전 종목을 **같은 기준**의 점수로 본다 | 줍줍·뉴지스탁은 국내만, 초이스스탁은 미국만·유료 | 핵심. 모든 화면의 중심 |
| 점수가 **왜 바뀌었는지** 축별로 설명하고, 「업종 N개 중 M위」로 분모를 보인다 | Seeking Alpha·Danelfin은 영어·유료 | 핵심. 한국어·무료가 자리 |
| **과거 성적을 숨기지 않는다**(지면 진 대로) | 대부분 성과를 마케팅으로 쓴다 | 신뢰 자산. 표본이 쌓일 때까지 「추천」이라 부르지 않는다 |
| 웹 검색에서 바로 닿는다(업종·스타일·비교·서프라이즈 롱테일) | 토스·줍줍은 앱 안에 있다 | 유입 무기. QP-05·07이 이 자산을 지킨다 |
| 해외 레딧 화제를 한국어로 요약 | ApeWisdom·Quiver는 영어 | 차별적이지만 약관 회색. 요약·수치만 |

## 6. 하지 않을 것

- **매매 신호·손절가·목표 수익률**(AI시그널프로의 「매수 점수 90 이상」, Danelfin Trading Parameters): 종목별 매매 판단은 유사투자자문 신고 대상이다. 우리 포지션(설명 가능한 점수)과도 충돌한다.
- **실시간 어닝콜 번역**(토스, 국내까지 확대해 누적 60만): 규모 경쟁이라 따라가지 않는다. 실적 요약과 서프라이즈 이력으로 충분하다.
- 부동산·예적금·커뮤니티에 새 투자(사용자 1,000명 전), 조회 경로의 LLM, 「10점 종목 누적 수익」식 성과 마케팅.
