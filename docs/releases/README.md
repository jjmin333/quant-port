## v1.12.1로 복원하기 (v1.13.0 되돌리기)

v1.13.0은 **프론트엔드 + nginx 설정**입니다 — 엣지에서 스캐너 노이즈(wp-admin·php·zip 등)를 444로 끊고, 모바일 종목 헤더의 잘림과 뉴스 카드 배지 정렬을 고치고, 뉴스에 「속보만」 필터를 더하고, 종목·지수 칩을 앱 공통 퀵룩 모달로 바꾸고, 종목 퀵룩에 일별 종가 토글·AI 핵심 요약·최근 일별·동작 다섯을 더하며, 발표가 없는 달에 안내를 세웁니다. **BE 변경·스키마 변경 없음.**

```powershell
git restore --source v1.12.1 fe/src docker-compose.yml deploy/nginx/app_routes.conf deploy/nginx/app_routes.host-fe.conf
Remove-Item -Force deploy/nginx/block_noise.conf, fe/src/lib/news-breaking-filter.ts, fe/src/lib/news-breaking-filter.test.ts, fe/src/lib/daily-close-window.ts, fe/src/lib/daily-close-window.test.ts, fe/src/lib/earnings-empty.ts, fe/src/lib/earnings-empty.test.ts, fe/src/components/providers/quick-look-provider.tsx, fe/src/components/charts/daily-close-range-toggle.tsx, fe/src/components/charts/daily-close-mini-table.tsx, fe/src/components/stocks/stock-quick-look-actions.tsx
docker compose --profile prod up -d --no-deps --force-recreate nginx
```

되돌리면 **wp-admin·php·zip 스캔이 다시 Next까지 들어와** 요청마다 200ms대를 태우고, 모바일 종목 헤더의 시장·시각이 다시 잘리며, 뉴스 카드의 배지 기둥이 흔들리고, 종목 뉴스 탭의 기사가 앱 밖으로 나가며, 속보 필터·퀵룩 창·종목 퀵룩의 새 블록 넷·실적 빈 달 안내가 사라집니다.

에이전트: **「v1.12.1로 복원해줘」** → `v1.13.0.md` §「v1.12.1로 복원하기」.
