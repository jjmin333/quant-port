```powershell

# v0.1.2 코드 상태로 되돌리기 (브랜치 유지)
```

에이전트에게 **「v0.1.2으로 복원해줘」**라고 요청하면:

1. `docs/releases/v0/v0.1/v0.1.2.md`를 기준 스펙으로 읽음
2. `git checkout v0.1.2 -- .` 또는 `git reset --hard v0.1.2` (사용자 확인 후)
3. `v0.1.2.md`의 **복원 후 확인 체크리스트** 실행
4. BE `.\scripts\restart.ps1 -Background`
