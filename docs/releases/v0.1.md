## 4. 완료된 기능

### 4.1 실시간 시세 (Quotes)

- **Terminal:** 현재가, 호가, 체결, 캔들 차트, SSE 스트림
- **장중:** Toss live poller → Redis + **MySQL write-through**
- **장 마감/주말:** DB-first → Redis warm → cold miss 시 Toss 1× backfill
- **캔들:** `candle_bars` (1m·1d 저장, 5m~1M 집계), 페이지네이션, SSE merge
- **v0.1 차트 개선:**
  - `bar_time` 정규화 + DATETIME migration (`MigrateCandleBarsV2IfNeeded`)
  - 집계 구간 `nextBefore` 분리 (1m vs 1d 기준)
  - FE 세션 뷰, 실시간 `update()`, 라이브 edge 추적
  - 차트 툴바: 우측 상단 **분봉(1·5·10·30·60·일·주·월) + 차트 형식(바·캔들·영역)** — 줌/전체화면 툴바 제거(레거시 UI)
  - 테마별 CSS 변수 `:root` 통일 (light/dark/midnight)

### 4.2 시장 지수

- KOSPI/KOSDAQ/USD·KRW, 나스닥·S&P·VIX·BTC·금 등
- Provider batch refresh (Toss/FRED/Finnhub), EOD persist → `market_indices`
- 문서: `docs/MARKET_INDICES_BATCH.md`

### 4.3 뉴스

- 국내: Naver API Hub + Kakao + RSS (한경·매경·서울경제·연합 등)
- US: Reader API 데모 1건
- **v0.1 한계:** 네이버 URL 기준 → 뱃지「네이버뉴스」, iframe 미리보기 제한, 썸네일 없음  
  → **v0.2 설계만 완료** (`originallink`, 언론사 뱃지, og:image — 미구현)

### 4.4 포트폴리오·계좌

- BE: Toss OAuth, broker link, portfolio sync/live/history **구현 유지**
- FE: **`ACCOUNT_FEATURES_VISIBLE=false`** — 홈·사이드바·설정에서 계좌/포트폴리오 UI 대부분 숨김

## 5. 데이터 아키텍처 (v0.1 정책)

**원칙:** MySQL = source of truth, Redis = hot cache

### MySQL 테이블 (migration 001–012)

| Migration | 테이블/변경 |
|-----------|-------------|
| 001–006 | users, broker, watchlist, snapshots, stocks, auth |
| 003 | `candle_bars` |
| 007–010 | portfolio cache, fx, indices, news |
| 011 | quote terminal persist (detail, orderbook, trades, last_prices) |
| 012 | candle_bars DATETIME (Go migration, SQL placeholder) |

### Read chain (Quotes)

```
Redis (TTL) → Redis last-good → MySQL → Toss 1× backfill → persist
```

## 6. 환경·실행 (v0.1)

### 필수

- MySQL 로컬, `be/.env` → `MYSQL_DSN`
- Redis: `docker compose up -d`
- Toss API 키 (시세·지수)
- (선택) Naver API Hub, FRED, Finnhub — 뉴스/지수

### BE 재시작 (Windows)

```powershell
cd be
.\scripts\restart.ps1 -Background
```

로그: `be/tmp/api.log`  
**금지:** `go run ./cmd/api` (방화벽 팝업)

### FE

```powershell
cd fe
npm install
npm run dev
```

→ http://localhost:3000
