# Quant Port v0.9.0 — Project Snapshot (뉴스 브리핑 LLM 입력)

> **버전:** v0.9.0
> **기준일:** 2026-08-21 (KST)
> **Git 태그:** `v0.9.0` (커밋 후)
> **이전 버전:** [v0.8.0](../v0.8/v0.8.0.md)
> **목적:** 홈 카드 「오늘의 시장 브리핑」이 제목만 보고 추측하던 실적·수급·금리를, 서버가 고른 숫자로 넣고, 잡음 헤드라인은 뒤로 보내 문장이 시장 이야기에 가까워지게 한다. 페이지 로드는 여전히 LLM을 부르지 않는다.
> **범위:** 백엔드(브리핑 promptJSON·실적 점수·Toss 수급 캐시·FRED DGS10) + 프론트(홈 지수 티커 카탈로그) + 릴리스 문서

---

## 1. 한 줄 요약

시장 브리핑 LLM 입력에 **실적(국내 확정 6 / 해외 ±7일 10, 서버 중요도 점수)**, **코스피 외국인·기관 순매수(억원, 장중 잠정)**, **미 국채 10년(DGS10)** 을 넣고, 이력은 **3건 + 직전 watchPoints**, 헤드라인 40은 **속보·언급종목·시장 키워드 우선**으로 고른다. 호출당 사전할당 토큰은 이력이 줄어서 오히려 약 10% 감소한다.

## 3. Phase별 구현 내용

### Phase 1 — 실적 압축 + 중요도 점수

국내: 최근 7일 **확정만**, 최대 6. 예정일 소스 없음. 해외: −7~+7일 확정+예정, 최대 10. `|서프라이즈|>200`은 단위 깨짐으로 0점. 점수는 선정용이며 프롬프트의 `imp`는 인용 금지.

`min(100, cap + surprise + reaction + soon)`. 국내 시총 100조+=80. 해외 $200B+=80. 임박 보너스는 해외 scheduled만.

### Phase 2 — 외국인·기관 순매수

브리핑 **생성 시** Toss KOSPI 1회. `frNet`/`insNet` 억원. 장중이면 `p:true`. Redis `briefing:investor-flow:v1:KOSPI` 5분. 페이지 로드는 호출하지 않음.

### Phase 3 — 미 국채 10년

카탈로그 `us10y` / FRED `DGS10`. `fred:us` 6시리즈. 스냅샷 키 `quotes:indices:snapshot:v2` + 카탈로그 길이 정렬로 구 12종 스냅샷이 sox/금을 밀지 않게 함.

### Phase 4 — 이력 3 + watchPoints, 헤드라인 재정렬

`briefingHistoryCount=10→3`. 최신 1건에만 `watchPoints`. 헤드라인은 속보 +3, 언급종목 +4, 시장 키워드 +2, 재산공개/팟캐스트/출근길/연예 −5. 40건·매체당 5는 유지.
