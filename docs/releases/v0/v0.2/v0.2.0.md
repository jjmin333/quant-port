## 3. Shell 모드 (Frontend)



### 3.1 감지 (`fe/src/lib/shell-mode.ts`)


| 모드        | 조건                                                        |
| --------- | --------------------------------------------------------- |
| `webview` | URL `?webview=1` / `?embed=1`, sessionStorage, WebView UA |
| `mobile`  | viewport `< 1024px` (webview 아님)                          |
| `desktop` | 그 외                                                       |


`document.documentElement.dataset.shell` 에 반영 → CSS 변수 오버라이드.

### 3.2 CSS (`globals.css`)

compact shell 시:

- `--header-min-width: 0`
- `--dashboard-content-min: 0`
- `--news-content-max: 100%`
- `--news-content-gutter: max(1rem, 4vw)`
- webview: `safe-area-inset-bottom` 패딩



### 3.3 AppShell

- **webview**: Sidebar 미표시, Header `showSidebarToggle={false}`
- **compact**: content `min-w-0`, horizontal overflow 제거
- viewport: `100dvh`



### 3.4 Header (모바일·웹뷰)

```
[☰] [◆ QUANT PORT]          [설정][프로필]
[────────── 검색바 (전체 너비) ──────────]
```

- 로고: `text-[10px]`, tracking 축소
- 검색: `StockSearchField compact`, `min-w-0`, Portal 자동완성 유지
- 알림 버튼: compact에서 숨김

- 종목 분석·국내 뉴스 (bare + 기존 shell)

## 5. 실시간 시세 (모바일)

- **compact**: 세로 flex — 종목 목록 `max-h-[42vh]` + 상세 패널 + 하단 「종목 분석」
- **desktop**: 기존 좌우 분할 (`min-w-[720px]`)

---



## 6. 웹뷰 연동 가이드

앱 WebView에서 첫 로드 URL 예:

```
https://your-host/analysis?symbol=005930&webview=1
```

- `webview=1`은 sessionStorage에 유지되어 이후 내비게이션에도 compact shell 적용.
- 사이드바 없이 본문만 표시 — 네이티브 앱 하단 탭과 조합 가능.
