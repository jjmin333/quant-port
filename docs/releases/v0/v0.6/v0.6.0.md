# Quant Port v0.6.0 — Project Snapshot (전망 탭 + 내부자 거래 탭 구현)

> **버전:** v0.6.0
> **기준일:** 2026-08-07 (KST)
> **Git 태그:** `v0.6.0` (커밋 후)
> **이전 버전:** [v0.5.0](../v0.5/v0.5.0.md)
> **목적:** **신규 기능** — 종목 워크스페이스의 `전망`·`내부자 거래` 탭(둘 다 "준비 중" 플레이스홀더)을 무료 데이터 소스만으로 실제 데이터로 채움. 같은 개발 세션에서 먼저 구현되었으나 미출시 상태로 남아있던 `재무제표` 탭 상세 모달·다분기 히스토리, DART/EDGAR 최신성 비교, 마켓 레이더 탭 유지 버그 수정도 이번 버전에 함께 묶어 출시
> **범위:** 백엔드(신규 엔드포인트 2개, DART elestock.json/EDGAR Form 4 연동) + 프론트엔드(신규 탭 컴포넌트 2개, 상세 모달 1개, 버그 수정 2건)

---

## 1. 한 줄 요약

`전망` 탭에 실적추세·밸류에이션 맥락·공시일정을, `내부자 거래` 탭에 임원·주요주주 매매 내역(국내 DART elestock.json, 미국 SEC Form 4)을 실제 데이터로 채웠습니다. 함께 묶어 출시하는 `재무제표` 탭 상세 모달은 클릭 시 다분기 실데이터 차트를 보여주고, DART/EDGAR 최신성 비교는 미국 20-F 겸업 국내 종목의 재무 데이터를 더 최신 소스로 자동 교체합니다.

## 3. Phase별 구현 내용

### Phase 1 — 백엔드: 신규 엔드포인트 `GET /api/v1/stocks/{symbol}/insider`

`InsiderTabService`가 국내/미국 여부(`ResolveFundamentalsAssetType`)에 따라 분기:

- **국내(DART `elestock.json`)**: 임원ㆍ주요주주 소유보고는 날짜 범위 파라미터가 없는 API로, 회사의 전체 보고 이력을 한 번에 반환 — 최근 30건으로 잘라 표시. 보고자명·등기여부/직위/주요주주여부(`Relation`)·소유 증감 수량·증감율·변동 후 보유수량·지분율을 그대로 매핑.
- **미국(SEC Form 4)**: 이 데이터는 두 단계로만 얻을 수 있음 — (1) 발행사 CIK의 `submissions.json`으로 최근 Form 4/4-A 신고 목록(접수번호) 조회, (2) 각 신고의 원본 소유보고 XML(`ownershipDocument`)을 개별 fetch해 보고자명·관계(이사/임원/10%주주)·거래코드(P=매수, S=매도, G=증여, M=파생상품행사, F=세금원천징수 등 SEC 고정 코드 19종)·거래수량·거래단가·거래 후 보유수량을 파싱. 최근 3건 신고로 제한(아래 사이드이펙트 참고).
- Redis 24h 캐시(`insider:tab:kr:v1:*`, `insider:tab:us:v1:*`) — `EarningsTabService`와 동일 패턴.

### Phase 2 — 백엔드 버그 수정: EDGAR 예산 소진 시 빈 결과가 24시간 캐시에 갇히던 문제

구현 중 실측 검증 과정에서 발견: `apibudget.ProviderEdgar`는 분당 8회로 앱 전체가 공유하는 예산인데, US 심볼 하나의 내부자 거래 조회가 `submissions.json`(1) + Form 4 원본 XML(최대 5회, 최초 티커 캐시 미스 시 `company_tickers.json`까지 +1)로 최대 7회를 소비. 여러 US 심볼을 짧은 시간에 연달아 조회하면 이 예산이 소진되어 개별 Form 4 fetch가 전부 실패하는데, 기존 코드는 이 실패를 필당 단위로 조용히 건너뛰기만 해서 **"신고는 있지만 전부 실패"인 상태를 "신고 없음"으로 오인해 빈 배열을 24시간 캐시**해버리는 문제가 실측(MSFT)으로 확인됨. `EdgarClient.FetchInsiderTransactions`가 "시도한 신고가 있는데 전부 실패"일 때는 에러를 반환하도록 수정해 `InsiderTabService`가 이 경우 캐시하지 않고 다음 요청에서 재시도하도록 함. 예산 소비 자체도 줄이기 위해 신고 개수 상한을 5→3으로 낮춤.

### Phase 3 — 전망 탭 구현 (BE 변경 없음, 기존 엔드포인트 재사용)

실적추세(`financials/history`)·밸류에이션 맥락(PER/PBR + PSR은 FE에서 `price×shares/revenue`로 신규 계산, "FY{연도} 실적 기준 · DART/EDGAR" 라벨)·공시일정(`earnings`의 `calendar`, `CalendarSection`을 `earnings-tab.tsx`에서 export해 공유)·컨센서스 안내 블록 4섹션. DART 잠정실적 공시 "본문" 파싱(자유 형식 문서)은 범위 밖으로 명시.

### Phase 4 — DART/EDGAR 최신성 비교

SEC `company_tickers.json` 실측으로 20-F(외국민간발행인 연차보고서)를 실제로 제출하는 국내 종목 7개만 매핑(`krxToEdgarTicker`: SK텔레콤·KB금융·신한지주·우리금융지주·POSCO홀딩스·한국전력·LG디스플레이 — 삼성전자·SK하이닉스는 무보증 ADR이라 대상 아님). `PeriodEnd` 비교로 EDGAR가 DART보다 진짜 더 최신일 때만 교체. 부수 수정: `FetchAnnualFinancialSnapshots`가 `PeriodEnd`를 채우지 않던 버그(`calendarQuarterEnd` 재사용해 채움) — 이 필드 없이는 애초에 비교가 불가능했음.

### Phase 5 — 마켓 레이더 탭 유지 버그 수정

`market/page.tsx`의 `selectSymbol`/URL-sync 두 곳에 있던 강제 `setWorkspaceTab("overview")` 제거. 각 탭이 이미 `symbol` prop 변경 시 자체 재조회하므로 탭 유지만으로 안전.

### Phase 6 — 재무제표 탭 상세 모달 + 다분기 히스토리

신규 `GET /stocks/{symbol}/financials/history?years=N`(기본 3, 최대 5): 국내(DART)는 손익 항목을 1~3분기 `thstrm_amount` 직접 사용 + 4분기는 `연간 − 3분기 누적` 역산, 재무상태표는 시점값 그대로. 미국(EDGAR)은 기존 분기 함수에 재무상태표 concept 추출만 추가(API 호출 증가 없음). 라이브 검증 중 버그 3건 발견·수정: DART 반기보고서의 "반기순이익" 계정명 폴백 누락, SEC XBRL이 동일 분기를 다른 `fy` 태그로 중복 보고하던 문제(매칭 키를 FY 제외 (FP,End)로 변경), 재무상태표 항목에 분기 duration 검증이 잘못 적용되지 않도록 별도 instant 매처 분리. FE `FinancialDetailModal`(3-preset + 콤보차트 + 연도토글) 신규.

## 9. 후속 (이번 릴리스 범위 밖)

- 내부자 거래 탭 US 쪽은 Form 4 최근 3건 신고로 제한 — 더 긴 이력이 필요하면 EDGAR 예산 소비와 트레이드오프를 재검토해야 함
- Form 4 파생거래(옵션/RSU) 테이블 미표시 — 필요 시 별도 섹션으로 추가 검토
- DART `elestock.json`도 30건으로 절단 — 대형주는 임원 수가 많아 최근 며칠치만 노출될 수 있음(페이지네이션 미구현)
- 내부자 거래에 대한 시각적 강조(예: 대량 매도 하이라이트, C-suite 거래 배지) 등 UX 개선은 범위 밖
