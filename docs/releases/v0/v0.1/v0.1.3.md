## 3. 종목 분석 (Frontend)

### 3.1 레이아웃 · 내비게이션

- **`analysis-client.tsx`**: `news-page-shell` — 중앙 정렬·반응형 gutter (`4vw`), 세로 스크롤 단일 컬럼
- 좌측 종목 사이드바 제거 → **상단 검색바**로 종목 선택
- **`analysis-tab-bar.tsx`**: 가로 스크롤 탭 (좁은 화면·웹뷰 대응)
- URL: `/analysis?symbol=…&tab=company|valuation|financials|earnings|outlook|insider`

### 3.2 탭 콘텐츠

| 탭 | 컴포넌트 | 내용 |
|----|----------|------|
| 기업 정보 | `company-info-tab.tsx` | 그리드 + 도넛(세그먼트) |
| 밸류에이션 | `valuation-tab.tsx` | 서브탭 **배수**(PER/PBR/PSR) · **지표**(2열 카드) |
| 재무제표 | `financials-charts-tab.tsx` | 6종 recharts (펀더멘털 기반) |
| 실적·전망·내부자 | `analysis-placeholder-tab.tsx` | 준비 중 플레이스홀더 |

### 3.3 라우팅

- **`/stocks/[symbol]`** → `/analysis?symbol=…` 리다이렉트
- 시세 패널 **「종목 분석」** → `/analysis?symbol=…&tab=valuation`

## 5. 종목 검색 (Frontend · Backend)

### 5.1 헤더 · 시세 공통

- **`stock-search-field.tsx`**: 검색 입력 + X + 자동완성 (default / compact)
- **`header-stock-suggestions.tsx`**: `createPortal` + `fixed` — overflow 클리pping 방지
- **`header-search-provider.tsx`**: `searchStocksCatalogClient(q, "", 5)`, Enter/클릭 시 종목 선택
- **`app-shell.tsx`**: 헤더 래퍼 `overflow-visible` + `z-50`

### 5.2 버그 수정

- `<input type="search">` 브라우저 기본 X + 커스텀 X **중복** → `type="text"` + `role="searchbox"`

### 5.3 랭킹 기준 (BE)

1. **텍스트 관련성** — 심볼 일치 > 접두사 > 한글명·영문명 매칭  
2. 동점 시 **발행주식수** (`sharesOutstanding`) — 시가총액 아님  
3. **`stock_search.go`**: 3글자 이하 영문 → 국내 `english_name` 접두(SK하이닉스 등)

### 5.4 실시간 시세

- **`quotes-symbol-list.tsx`**: 필터 탭 아래 **compact 검색바**
- **`quotes/page.tsx`**: `registerStockPickHandler` — 자동완성 선택 시 종목 전환
