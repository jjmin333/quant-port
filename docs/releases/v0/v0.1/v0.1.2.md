## 3. 캔들 SWR (Backend)

### 3.1 `EnsureCandleSnapshot` (장중)

```
Redis hit     → 즉시 반환
Redis miss    → DB hit → 즉시 반환 + triggerRawCandlesRefresh (비동기)
DB miss       → doSync(refreshRawCandles) — cold start만 동기 대기
```

- **`prepareCandleSnapshotResponse`**: Rev·KRW 정규화 공통화
- **`triggerRawCandlesRefresh`**: 기존 `runOnce("rawcandles:"+sym)` 재사용
- **장 마감 경로**: v0.1.1과 동일 (DB 우선)

### 3.2 기대 효과

- Redis TTL 만료·재기동 후에도 **DB에 이력이 있으면** HTTP가 Toss를 기다리지 않음
- SSE `rev` bump로 클라이언트는 백그라운드 갱신 후 자동 반영
