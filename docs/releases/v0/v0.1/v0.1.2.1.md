## 3. 원인 · 수정 (Backend)

### 3.1 증상

- 현재가 230,500원 고정인데 **+44,500** ↔ **-24,500** 번갈아 표시
- `전일` 필드도 186,000 ↔ 255,000 등으로 불안정

### 3.2 원인

`statsFromRawCache`가 Redis 일봉 배열의 **`raw1d[1]`** 을 전일 종가로 사용.

- Toss tail 캐시(최신→과거): `[1]` = 어제 → 우연히 맞음
- DB warm 캐시(과거→최신, ~200봉): `[1]` = **수개월 전** 종가(예: 186,000) → 잘못된 +등락

SWR 도입 후 DB 캐시 hit 빈도가 올라가며 증상이 두드러짐.

### 3.3 수정

- **`prevCloseFromDailyCandles`**: bar_time 기준 정렬 → `sorted[len-2].Close`
- `statsFromRawCache`, `statsFromDBCandles` 공통 사용
- 테스트: `be/internal/service/quotes_stats_test.go`

## 4. 원인 · 수정 (Frontend)

`QuoteChange` (KRW)가 `Math.abs(change)` + 양수일 때만 `+` 접두 → 하락 시 `-` 누락.

- **`formatPriceChange(change, "KRW")`** + **`formatPercent(changeRate)`** 로 통일
- `formatPriceChange` KRW: `sign` + `formatAmount(abs)` 로 명시적 부호
