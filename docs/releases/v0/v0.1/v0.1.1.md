## 3. 뉴스 (Backend)

### 3.1 DB · Migration

- **`013_news_preview.sql`**: `original_url`, `portal_url`, `publisher_id/name`, `image_url`, `preview_mode`
- Redis snapshot key: **`news:domestic:snapshot:v3`**

### 3.2 Ingest

| 소스 | 동작 |
|------|------|
| Naver API Hub | `originallink` + portal URL, 키워드 로테이션 (18개/2분) |
| Kakao | 키워드 + 「뉴스」(4개/20분) |
| RSS | 한경·매경·서울경제·연합경제·**더팩트** |

- **언론사 해석:** `naver_press.go` (Naver `oid` → 매체), `publisher.go` (URL 규칙)
- **와이어 URL:** `originallink`가 newspim 등일 때 portal `oid` 우선
- **og:image:** `news_preview.go` ingest + `news_store_backfill.go` (200건 배치)
- **중복:** `original_url` 기준 dedupe on ingest
- **조회수:** `POST /api/v1/news/view`, `view_count` 컬럼

### 3.3 증권 관련성 필터 (v0.1.1 신규)

- **`news_relevance.go`**: ingest 전 `isStockRelated()` 6단계 판정
  - 비증권 주제 차단 (교도소·여론조사·관광 등)
  - 경제 RSS 완화 (`TrustEconomyFeed`)
  - 추적 종목명·금융 키워드 필수 (넓은 검색어 AI·외국인 등)
- **적용:** Naver · Kakao · RSS 공통 (`ingestItem` 게이트)
- **DB 정리:** `be/cmd/cleanup-news` — 기존 row 일괄 재판정·삭제

```powershell
cd be
go build -o bin/cleanup-news.exe ./cmd/cleanup-news
.\bin\cleanup-news.exe -dry-run
.\bin\cleanup-news.exe
```

### 3.4 API

| 엔드포인트 | 비고 |
|------------|------|
| `GET /api/v1/news/domestic` | `source`, `sort`, `q`, `symbol` |
| `POST /api/v1/news/view` | 조회수 |
| `GET /api/v1/news/reader?url=` | Reader 본문 |
| `GET /api/v1/news/us/demo` | RSS → Reader 데모 |
