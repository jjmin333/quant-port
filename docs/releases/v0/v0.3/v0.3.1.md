# Quant Port v0.3.1 — Project Snapshot (종목 로고 추가)

> **버전:** v0.3.1  
> **기준일:** 2026-07-29 (KST)  
> **Git 태그:** `v0.3.1` (커밋·태그 생성 후)  
> **이전 버전:** [v0.3.0](./v0.3.0.md)  
> **목적:** FMP `image-stock` CDN 기반 **종목 로고** — DB migration 없이 runtime URL 생성

---

## 1. 한 줄 요약

국내·해외 종목에 **회사/ETF 로고**를 표시합니다. URL은 FMP CDN에서 `symbol` 규칙으로 **매번 계산**하며 DB에 저장하지 않습니다. 신규 상장·로고 변경은 FMP 쪽 갱신에 따라 자동 반영되고, 로드 실패 시 **monogram fallback**을 사용합니다.

---

## 2. v0.3.0 → v0.3.1 변경 요약

| 영역 | v0.3.0 | v0.3.1 |
|------|--------|--------|
| 종목 로고 | 없음 | FMP `image-stock` CDN |
| DB | — | **migration 없음** (`logo_url` 컬럼 없음) |
| API | — | `logoUrl` **computed field** (quotes·stock search) |
| FE | — | `StockAvatar` + 검색·시세·상세·관심·보유 UI |
| 외부 API 호출 | — | **0회** (브라우저가 FMP CDN 직접 요청) |
| FE package | `0.3.0` | `0.3.1` |

---

## 3. FMP URL 규칙

| 시장 | 규칙 | 예시 |
|------|------|------|
| 국내 (`KRW` / `domestic` / KRX·KOSDAQ) | `{symbol}.KS.png` | `005930.KS.png` |
| 해외 (`USD` / `us` / `etf`) | `{symbol}.png` | `SNDK.png`, `TQQQ.png` |

Base URL: `https://financialmodelingprep.com/image-stock/`

### 로고가 표시되는 화면

- 글로벌 헤더 종목 검색 제안
- `/quotes` 종목 목록
- `/stocks/{symbol}` 종목 상세 헤더
- `/watchlist` 관심종목
- `/holdings` 수동 보유 목록

---

## 5. 알려진 제한

- FMP 미등록 신규 종목(예: `0193W0` 국내 2x ETF) → 404 → monogram
- 국내 ETF 다수는 FMP **공통 placeholder** 이미지
- US 레버리지 ETF는 **기초자산이 아닌 발행사/펀드** 로고
- FMP Legacy CDN — 장기 ToS/URL 변경 시 fallback으로 UX 유지
