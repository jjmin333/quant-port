## 1. 한 줄 요약

토스 API 연동 없이도 **증권앱 스크린샷(최대 10장)** 으로 보유종목을 등록할 수 있습니다. BE는 이미지별 **병렬 OCR·파싱·종목 매칭**을 비동기 job으로 처리하고, FE는 **자르기 → 진행 표시 → 미리보기·수정 → 저장** 흐름으로 사용자 확인을 거칩니다.

## 3. 사용자 흐름 (Frontend)

```
/holdings → [스크린샷으로 가져오기]
  → 이미지 선택 (≤10) + 영역 드래그 crop (선택)
  → [분석 시작] → "데이터 처리 중…" (job 폴링, progress bar)
  → 미리보기 테이블 (종목코드·수량 수정, 체크박스)
  → [N개 저장] (+ 관심종목에도 추가 옵션)
  → 보유 목록 + held 시세 표시
```

## 4. Backend API


| Method   | Path                                          | 설명                                             |
| -------- | --------------------------------------------- | ---------------------------------------------- |
| `POST`   | `/api/v1/import/holdings/screenshots`         | multipart `images` + `meta` JSON → `{ jobId }` |
| `GET`    | `/api/v1/import/holdings/jobs/{jobId}`        | status, progress, preview                      |
| `POST`   | `/api/v1/import/holdings/jobs/{jobId}/commit` | 선택 행 저장, `addToWatchlist`                      |

| `POST`   | `/api/v1/watchlist/bulk`                      | 관심종목 일괄 추가                                     |

## 5. Backend 처리 (속도)

- 업로드 즉시 **202 Accepted** + jobId, OCR는 **백그라운드 goroutine**
- 이미지마다 **독립 worker** (crop → grayscale → Tesseract → `N주` 파싱 → 종목 검색)
- job 상태·preview는 **Redis** (`import:holdings:job:{id}`, TTL 24h)
- temp 파일은 preview 완료 후 삭제, **6시간마다 24h+ orphan sweeper**
- holdings 읽기: `holdings:manual:v1:user:{id}` — commit/PUT/DELETE 시 즉시 invalidate



### DB

- `be/migrations/014_user_holdings.sql` — `user_holdings (user_id, symbol, quantity, …)`



### OCR 의존성

**Docker only** — `be/Dockerfile`에 Tesseract(`kor+eng`) 포함. `be/scripts/restart.ps1`이 기동 후 로그로 Tesseract 상태를 검증합니다.

미설치/오류 시 job `failed` + FE 수동 종목코드 입력 가능.

### Docker / 임시 이미지

- `IMPORT_TEMP_DIR` — `/var/lib/quant-port/import` (컨테이너 writable layer, **tmpfs 미사용**)
- 삭제: OCR/preview·commit 시 `RemoveAll(jobDir)` + 24h orphan sweeper
- 상세: [`be/docs/docker.md`](../../../../be/docs/docker.md)

## 7. 알려진 제한 (v0.3.0)

- 평균단가·매입일·증권사별 분리 수량은 OCR 범위外 (수량·종목 중심)
- 토스 API 보유와 수동 보유는 **병존** (시세 `held`는 합집합); `/holdings` UI는 수동 보유만 표시
- JPG/PNG만 지원 (FE 차단 + BE 거부); WEBP·HEIC 등 불가
