# Quant Port v0.3.2.1 — Project Snapshot (시세 및 종목 조회 페이지 개선)

> **버전:** v0.3.2.1  
> **기준일:** 2026-07-30 (KST)  
> **Git 태그:** `v0.3.2.1` (커밋·태그 생성 후)  
> **이전 버전:** [v0.3.2](./v0.3.2.md)  
> **목적:** **「실시간 시세」→「종목 분석」** 명칭 통일, `/quotes` **헤더 검색** 정상화, 레거시 `/analysis` 정리

---

## 1. 한 줄 요약

사이드바·페이지 제목의 **「실시간 시세」를 「종목 분석」** 으로 변경했습니다. 기능은 v0.3.2 Stock Workspace와 동일하며, **상단 헤더 검색**으로 종목 선택·목록 필터가 동작합니다. 중복된 좌측 패널 검색창은 제거했습니다.

---

## 2. v0.3.2 → v0.3.2.1 변경 요약

| 영역 | v0.3.2 | v0.3.2.1 |
|------|--------|----------|
| 사이드바 `/quotes` | 실시간 시세 | **종목 분석** |
| 사이드바 `/analysis` | 종목 분석 (별도) | **제거** |
| `/quotes` PageHeader | 실시간 시세 | **종목 분석** |
| `/quotes` 검색 | 좌측 패널 + 헤더 (중복) | **헤더만** (데스크톱·모바일) |
| 헤더 검색 Enter | 제안 없으면 목록 필터만 | **심볼 파싱 → 종목 선택** |
| `/analysis` | defaultSymbol → `/stocks/…` | **→ `/quotes`** (symbol 있으면 `/stocks/…`) |
| FE package | `0.3.2` | `0.3.2.1` |

## 3. IA (정보 구조)

```
사이드바 「종목 분석」 → /quotes
  ├─ 헤더 검색: 자동완성 · Enter(심볼/제안) → 목록/워크스페이스 전환
  ├─ 좌측: 종목 목록 (필터: 전체·국내·미국·관심·보유)
  └─ 우측: Stock Workspace (v0.3.2 동일)

/stocks/[symbol]     — 딥링크·공유 (변경 없음)
/analysis            — 레거시 redirect only
/analysis?symbol=X   — /stocks/X?tab=…
```

---

## 4. 헤더 검색 동작 (`/quotes`)

| 동작 | 결과 |
|------|------|
| 자동완성 선택 | `registerStockPickHandler` → 종목 전환 (+ 모바일 상세) |
| Enter + 제안 있음 | 하이라이트 종목 선택 |
| Enter + `005930` / `NVDA` | 심볼 파싱 → 종목 선택 |
| Enter + 한글명 (제안만) | `activeQuery`로 **목록 필터** |
| Escape | 검색 초기화 |

모바일·웹뷰: 헤더 2행(브랜드 + 검색) — `Header` compact 레이아웃 유지.
