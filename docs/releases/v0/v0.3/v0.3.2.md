## 1. 한 줄 요약

종목을 고르면 **개요 · 차트·시세 · 기업정보 · 밸류에이션 · 재무** 등을 한 화면(탭)에서 볼 수 있습니다. 데스크톱 `/quotes`는 좌측 종목 목록 + 우측 워크스페이스, 모바일·웹뷰는 **목록 ↔ 상세** 마스터-디테일로 전환합니다.

## 2. v0.3.1 → v0.3.2 변경 요약

| 영역 | v0.3.1 | v0.3.2 |
|------|--------|--------|
| 종목 상세 UX | `/quotes` 시세 패널 + `/analysis?symbol=` 분석 | **Stock Workspace** 통합 UI |

| 좌측 지표 컬럼 | 없음 | **lg+ 시세·거래·재무** (차트 탭에서는 숨김) |
| FE package | `0.3.1` | `0.3.2` |

## 3. 사용자 흐름

### 데스크톱 `/quotes`

```
좌: 종목 목록 (필터·검색·관심·보유)
우: StockWorkspace (헤더 · 탭 · 콘텐츠)
  → 탭 전환은 URL 변경 없이 패널 내 상태
  → 푸터 [밸류에이션 →] 는 /stocks/{symbol}?tab=valuation 새 탭/페이지
```

### 모바일·웹뷰 `/quotes`

```
목록 화면 → 종목 탭 → 상세(워크스페이스) + [← 목록]
  → safe-area 하단 푸터
  → 종목 변경 시 탭 overview로 리셋
```

### 직접 URL `/stocks/005930?tab=chart`

```
탭 = URL query `tab` (공유·북마크 가능)
사이드바 「실시간 시세」 활성 ( /stocks/* 매칭 )
```

### 레거시 `/analysis?symbol=NVDA&tab=valuation`

```
→ /stocks/NVDA?tab=valuation 자동 이동
심볼 없음 → 검색 안내 + /quotes 링크
```

## 4. 탭 구성

| tab id | 라벨 | 내용 |
|--------|------|------|
| `overview` | 개요 | 미니 일봉, 배수 요약, 탭 이동 카드 |
| `chart` | 차트·시세 | 캔들·호가·체결 (기존 quotes-detail 차트) |
| `company` | 기업 정보 | CompanyInfoTab |
| `valuation` | 밸류에이션 | ValuationTab |
| `financials` | 재무제표 | FinancialsChartsTab |
| `earnings` | 실적 | placeholder |
| `outlook` | 전망 | placeholder |
| `insider` | 내부자 거래 | placeholder |

정의: `fe/src/lib/stock-workspace-tabs.ts`
