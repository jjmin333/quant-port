## 3. Phase별 기능

### Phase 1
- `/market` TOP20 · 60s polling
- 툴바: 국내/미국 · 랭킹 타입 · 기간 · URL sync
- 행 클릭 → `StockWorkspaceClient` (`chart` 탭)
- 모바일 마스터–디테일 · 헤더 검색 연동

### Phase 1.5
- 행별 **일봉 스파크라인** (Intersection Observer lazy)
- **TOP5 정규화 수익률** 겹침 차트 (접기 가능)
- **보유·관심** 배지 · 「보유·관심만」 필터

### Phase 2
- BE: 랭킹 조회 시 **5분 간격 스냅샷** 저장
- `GET /api/v1/rankings/history?symbol=…`
- 선택 종목 **24h 순위 궤적** 미니 차트
- 폴링 간 **순위 변동 ↑↓** 배지 (클라이언트)
