# Quant Port v1.0.4 — 등락률 기준을 「전일 종가」로, 현재가를 「시간외까지 끝난 최종가」로 통일

> **버전:** v1.0.4
> **기준일:** 2026-09-01 (KST)
> **Git 태그:** `v1.0.4` (커밋 후)
> **이전 버전:** [v1.0.3](./v1.0.3.md)
> **목적:** 같은 종목의 같은 날 등락률이 화면마다 다르게 보이던 문제를 없앤다.
> **범위:** 백엔드(시세 계산 경로) + 프론트엔드(기준선·라벨). DB 스키마·배치 변경 없음.

---

## 1. 한 줄 요약

**현재가는 시간외까지 끝난 최종가, 기준은 언제나 전일 종가** — 이 한 규칙으로 목록·상세·홈을 통일했다. 예전에는 상세가 「당일 정규장 종가 대비」를, 목록이 「랭킹 기준가 대비」를 썼는데 **둘 다 마감 후에는 오늘 종가가 기준**이라, 나오는 숫자가 하루 등락률이 아니라 **시간외 등락률**이었다. 실측(2026-09-01 마감 후): SK하이닉스가 목록 **+2.36%** · 상세 **−0.06%**로 갈렸고, 이제 양쪽 다 −0.06%다. 12종목 교차 검증 **불일치 0**, 39종목 전부 전일 종가 기준.

## 2. 변경 요약

| 영역 | 이전 | 이번 |
|---|---|---|
| 등락률 기준 (마감·시간외) | 상세는 당일 정규장 종가, 목록은 랭킹 기준가 | **전일 종가** 하나 |
| 등락률 기준 (장중) | 전일 종가 | 그대로 — 이제 세션이 바뀌어도 기준이 안 바뀐다 |
| 마감 후 현재가 (목록) | 저장된 1일봉 종가(정규장) | **시간외까지 끝난 최종가** |
| 목록 vs 상세 | SK하이닉스 +2.36% vs −0.06% | 12종목 교차 검증 **전부 일치** |
| 기준가 출처 | 랭킹 basePrice 우선 | **저장된 1일봉의 「오늘이 아닌 최신 종가」** 우선 |
| FE 라벨 | 「정규장 종가 대비」 / 「전일 정규장 종가 대비」 | **「전일 종가 대비」** 하나 |
| 목록의 정규장 종가 조회 | 종목마다 1분봉 480행 | 조회하지 않음 (목록은 그 줄을 안 그린다) |

## 3. 원인 — 실측

### 3.1 기준이 세션에 따라 갈아타고 있었다

`computeQuoteChange`가 `after`·`closed`에서 「당일 정규장 종가」로 기준을 바꿨다. 그런데 현재가는 시간외까지 반영한 최종가라, 그 둘의 차이는 **하루 움직임이 아니라 시간외 움직임**이다.

```
005930  최종가 255,000 · 당일 정규장 종가 260,500 →  −2.11%  (표시되던 값)
        최종가 255,000 · 전일 종가     258,000 →  −1.16%  (그날 실제 움직임)
```

### 3.2 목록은 또 다른 기준을 쓰고 있었다

`resolvePrevClose`가 랭킹 `basePrice`를 1순위로 썼는데, 그 값은 **「그 세션의 기준가」라 정규장이 끝나면 오늘 종가로 갱신된다**(실측 `market:refprice:v3:005930` = 260,000 = 그날 정규장 종가). 장중에는 전일 종가와 같아 문제가 없다가, 마감 후에만 어긋났다.

### 3.3 현재가마저 경로마다 달랐다

마감 세션에서 상세는 업스트림 최종가를, 목록은 저장된 1일봉 종가를 썼다. 시간외에 거래가 있었던 날 두 값이 갈린다.

```
000660  1일봉(정규장) 1,692,000 → 목록 +2.36%
        최종가        1,652,000 → 상세 −0.06%
```

## 4. 수정 내용

| 파일 | 내용 |
|---|---|
| `be/internal/service/quote_change.go` | `computeQuoteChange(current, prevClose)` — 기준은 언제나 전일 종가. `regularClose`·`session` 인자 제거. 목록에서는 `resolveRegularClose`를 아예 부르지 않는다(표시용 값이라, 종목마다 1분봉 480행을 읽던 경로) |
| `be/internal/service/reference_price.go` | `resolvePrevClose` — **저장된 1일봉의 「오늘이 아닌 최신 종가」가 1순위**. 랭킹 기준가는 일봉이 없는 종목의 폴백으로 내려감. 시계열이 `prevCloseStaleWindow`(7일)보다 낡으면 빈손으로 나가 폴백에 넘긴다 |
| `be/internal/service/quote_live_price.go` | 마감 세션에서 **배치 최종가**가 저장된 1일봉보다 우선 |
| `be/internal/service/quotes_batch.go` | 배치 가격을 조건 없이 현재가로 seed(비어 있을 때만 채우면 낡은 상세가 남는다) |
| `be/internal/service/quotes_enrich.go` · `quotes_watchlist.go` | 새 시그니처에 맞춤 |
| `fe/src/lib/quotes-types.ts` | `quoteChangeBaseline`은 언제나 `prevClose`. `quoteChangeBasisLabel(quote)` → 상수 `QUOTE_CHANGE_BASIS_LABEL`(세션마다 다를 수 있다는 잘못된 신호를 없앤다) |
| `fe/src/components/{quotes,stock-workspace,stocks}` | 라벨 상수 사용 (4곳) |

`regularClose`는 **응답 필드로 남는다** — 상세 화면의 「정규장 종가」 줄이 그대로 쓴다. 계산에서만 빠졌다.

## 5. 사이드 이펙트·호환

| 항목 | 영향 |
|---|---|
| 마감 후 등락률 | 공식 일별 종가(정규장)와 다를 수 있다. **의도된 차이다** — 시간외에 움직인 종목은 그만큼 벌어진다(실측 39종목 중 17종목). 시간외 거래가 없던 22종목은 공식 값과 정확히 일치 |
| 외부 서비스와의 비교 | 거래소·네이버·토스가 「종가」로 발표하는 값은 정규장 종가다. 우리 화면은 시간외까지 반영하므로 그 값들과 다를 수 있다 |
| 얇은 세션의 영향 | 시간외 단일가는 거래량이 작아, 헤드라인 등락률이 소량 체결에 흔들릴 수 있다 |
| 이전 결정과의 관계 | v0.10 계열의 「마감 후에는 확정 종가를 쓴다」를 **뒤집는다**(사용자 결정: 「시간외까지 마감된 게 진짜 종가」). `quotes_live_change.go`의 관련 주석도 함께 고쳤다 |
| DB 부하 | 목록에서 `resolveRegularClose`(1분봉 480행/종목)가 빠지고, `prevCloseFromDailyBars`(인덱스 조회 1회)가 늘었다 — 순감 |
| 전일 기준의 비대칭 | 오늘은 시간외 포함, 전일은 정규장 종가다. 전일의 시간외 포함 최종가는 저장하지 않기로 했다(사용자 선택 A) |
